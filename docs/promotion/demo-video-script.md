# Memory Skill 演示视频脚本（30s wow moment）

> 用途：掘金 / 即刻 / B站 / X（Twitter）传播。
> 目标：让人看完 30 秒，立刻想自己试一下。

---

## 1. 视频定位（一句话）

**给 AI Agent 装上一副「不会失忆」的长期记忆：30 秒，看完一个从失忆到记住的真实演示。**

核心叙事弧线：AI 失忆痛点 → 装上记忆系统 → 重启后 AI 还记得 → 结尾留钩子（还能主动学习）。

## 5. 录制操作步骤

### 5.1 录制前准备

| 项目 | 要求 | 说明 |
|---|---|---|
| 系统 | macOS 或 Linux；Windows 用 WSL | 项目依赖 bash 脚本（`setup.sh` / `download_model.sh`） |
| 终端 | iTerm2 / Windows Terminal / tmux | 深色主题，字号调大到代码清晰，关闭浏览器等无关窗口 |
| Agent | OpenCode（TUI） | 演示主体；Claude Code / Cursor 流程相同，只是配置文件不同 |
| 录制 | OBS 或系统自带录屏 | 16:9，1920×1080，60fps；建议第二块屏放脚本提词 |
| 素材 | 全新空记忆库 | 用默认路径但确保是首次运行，或临时改 `MEMORY_SKILL_DB_PATH` 指向新库。**这是「失忆镜头」真实的前提** |

**关于失忆镜头怎么拍才真实（重要）**：先在没装插件的目录里，开一个新会话，告诉 AI 偏好，再开新会话问它，它会真的说不知道。这一段就是「失忆」素材。装上插件之后再重来一遍，就是「记得」素材。全程真实对比，不是演的。

### 5.2 分镜头录制清单

每个镜头对应分镜表场景，直接照着录。

| 镜头 | 操作 | 录制要点 |
|---|---|---|
| 失忆（场景 1-2） | 未装插件、空库。会话 A：输入「我偏好用 Python 写后端，代码用 2 空格缩进，数据库用 SQLite」；会话 B：问「我的技术栈是什么？」 | 两个会话窗口并排排好；中间等待剪掉。多录一次备用 |
| 安装（场景 3） | 依次执行：`git clone https://github.com/baaai123/solo-memory`、`cd solo-memory`、`./setup.sh`（若嵌入模型缺失再 `./download_model.sh`）、`cp .env.example .env` 并填 `IMPORTANCE_API_KEY`；用编辑器在 `~/.config/opencode/opencode.json` 的 `plugin` 数组加入插件路径；重启 opencode | 命令跑得慢没关系，剪辑加速。`.env` 里的 key 记得打码 |
| 存入（场景 4） | 装好后开新会话，输入同一条偏好，AI 确认回复 | 可补一帧证据：终端 `ls -lh memory.db` 显示文件存在；或 `sqlite3 memory.db 'select count(*) from ...'` 显示有记录（表名以实际为准，不确定就只拍文件存在） |
| 记得（场景 5-6） | 退出 opencode，重新打开新会话；输入「帮我写个连接数据库的脚本」；等 AI 回复，展示回复前的 `[记忆上下文]` 注入块与符合偏好的代码 | 这帧是全片重点：把注入块用画框 / 箭头高亮；多拍 2-3 遍，挑 AI 表现最顺的一遍 |
| 钩子（场景 7） | 无操作，剪辑时叠文字卡 | 文字卡文案见分镜表 |

### 5.3 必拍证据镜头（证明「记得」的三种方式）

观众信不信，全看这三类证据拍没拍全。至少各拍一段。

1. **注入证据**：回复前的 `[记忆上下文]` / `[用户偏好]` 区块完整出现在屏幕上，且内容包含上一条会话的偏好。高亮圈出。
2. **主动引用证据**：Agent 回复里主动说「按你之前定的方案」，或直接引用记忆标题（如「日志库选型」），随后展开完整上下文。这是 README 里的主动检索能力，拍出来最有说服力。
3. **行为证据（最强）**：新会话里你一个字都没提偏好，Agent 生成的代码却自动用了 Python + SQLite + 2 空格缩进。证明它记住了并且「用上了」，不只是复述。
4. （可选加分）**数据证据**：`memory_status` 健康检查输出正常，或数据库文件存在。

### 5.4 60 秒版额外镜头

- **weave 注入**：新会话首次回复前，整块 `[记忆上下文]` 八个区块拍清楚，逐条划过。
- **主动检索展开**：问「我们之前关于日志库的结论是什么？」，拍到 Agent 引用标题后上下文自动展开。
- **主动学习闭环**：依次拍 `memory_gaps` 列出的缺口 → 确认学习 → `memory_learn` 执行（爬取、合成）→ 记忆树新增 skill 节点。整个过程真实执行，不要跳步骤，剪辑时用倍速。
- **透明代理（可选）**：`DEEPSEEK_API_KEY=sk-xxx ./start.sh --port 8888`，再把 `OPENAI_API_BASE` 指到本地代理，演示 Agent 零改动也能有记忆。

### 5.5 剪辑节奏建议

- 30 秒版整体 BPM 偏快，字幕每句只留 1-2 秒。
- 「重启」镜头前留半秒黑场，制造悬念。
- 「它还记得」镜头是峰值：前面的节奏全部为这一帧蓄力，这里放慢半拍。
- 结尾定格卡片停留 2 秒以上，方便截图。
- 全片配中英双语硬字幕（下方中文、上方或下方英文），方便 X 端直接看。

### 6.5 传播红线（录之前读一遍）

- 不演示仓库里没有的能力：不出现「自动写完整项目」「跨 Agent 同步」「100% 记得」「永久记住」等表述。
- 不提「零成本」：检索本地化是真，但分类/合成/学习需要 LLM，走你自己的 API key 计费。
- 不夸大数字：93% 是 300 条记忆实测的中文检索精度，表述为「实测 93%」而非「接近完美」。
- 记忆权重随使用演化是真实特性，但效果因人而异，简介里已加说明。
- emoji 控制在每个平台标题最多 1 个，正文不堆砌。
